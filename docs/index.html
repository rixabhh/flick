CLEAR PRIVACY CONTROLS

Your words stay
under your control.

01

You choose the context

Flick uses only the text you select for a reply. It does not read your screen or collect whole conversations.

02

Flick checks before inserting

If you switch apps or start typing somewhere else, Flick keeps the result available to copy instead of pasting into the wrong place.

03

Your keys use the system keychain

API keys are stored by your operating system. Cloud dictation happens only after you turn it on and choose a provider.
