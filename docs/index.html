Privacy is a product feature

Helpful, without being nosy.

⌁

Selection, not surveillance

Reply context starts with text you explicitly select. Flick does not scrape chats, screens, or an accessibility tree.

⌘

Safe by default

Flick checks the original target before paste-back and falls back to copy when a field is protected or the target changed.

◌

Your credentials stay yours

API keys live in the operating system keychain, not in a settings file. Diagnostics are explicit and redacted.
