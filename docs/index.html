START IN FIVE MINUTES

From install to
your first dictation.

No new editor to learn. Set Flick up once, then use a shortcut from any supported text field.

  1. 1

    Install Flick

    Download the build for your computer: x64 or ARM64 on Windows, Apple Silicon or Intel on macOS, or x64 on Linux.

    Open downloads →
  2. 2

    Choose a speech model

    Open Models, pick a small local model, and select Download. Prefer cloud? Add your own transcription key under Dictate.

    Compare the choices →
  3. 3

    Pick your shortcuts

    Record your own dictation and reply shortcuts in Settings. Flick warns you if two actions use the same keys.

    See the defaults →
  4. 4

    Start writing

    Press the dictation shortcut and speak. Or select a message and open the compact reply assistant. Press Esc to cancel dictation.

    Learn all three workflows →
YOUR FIRST TRYPress the dictation shortcut → wait for “Recording” → speak → press it again.

The pill appears where you place it in Settings. Your result returns to the text field you started from.

CLEAR PRIVACY CONTROLS

Your words stay
under your control.

01

You choose the context

Flick uses only the text you select for a reply. It does not read your screen or collect whole conversations.

02

Flick checks before inserting

If you switch apps or start typing somewhere else, Flick keeps the result available to copy instead of pasting into the wrong place.

03

Your keys use the system keychain

API keys are stored by your operating system. Cloud dictation happens only after you turn it on and choose a provider.
