THREE SMALL MOMENTS

Helpful at exactly
the right time.

Flick is designed to be quiet until you call it. A shortcut or a small command opens one focused interaction, then gets out of the way.

01 / WRITE

Turn a rough thought into a clear one.

Type naturally. Add a command. Flick returns a polished version to the same text field—only when you ask.

Explore text commands →

02 / REPLY

Give a reply the context it deserves.

Select what matters, choose a tone, then edit the draft before you copy or deliberately insert it.

Explore reply drafting →

03 / DICTATE

Say the thought while it is still there.

Record with a model you choose. Keep audio local, or explicitly connect a cloud transcription provider with your own key.

TRUST IS PART OF THE INTERFACE

Useful without
watching over you.

01

Selection, not surveillance

Reply context begins with the text you select. Flick does not scrape your screen, chats, or accessibility tree.

02

Safe where it counts

Flick checks the original target before paste-back. If it changed or is protected, the result stays available to copy.

03

Keys stay in your keychain

Provider credentials are stored by your operating system—not in a settings file. Diagnostics are explicit and redacted.
